# Waqar Ahmed — Portfolio

A static portfolio for **Waqar Ahmed**, Senior Graphic Designer and event production specialist based in Dubai. It is built to host on **GitHub Pages** with no build step.

## Preview locally

Open a terminal in this folder and run:

```bash
python -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080).

## Publish on GitHub Pages

1. Create a new GitHub repository (public).
2. Push this project to the repository.
3. On GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, set:
   - **Source:** Deploy from a branch
   - **Branch:** `main` (or `master`)
   - **Folder:** `/ (root)`
5. Save. After a minute the site will be live at:

`https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/`

If you name the repository `YOUR-USERNAME.github.io`, the site will live at the root of that domain instead.

## What’s included

- Home hero and selected work gallery (with filters and lightbox)
- **Behind the Pixels** — bio and creative journey
- **Trusted Voices** — professional references (names and roles)
- **Let’s Connect** — email, phone, and LinkedIn
- Optimized images so the repo stays well under GitHub’s size limits

Original boards were compressed for the web. Keep the source files elsewhere if you need print-resolution versions.
